This is a placeholder for the GDPC Semifinal Case file.

To enable the Case Semifinal button functionality:
1. Upload the actual PDF file for the GDPC semifinal case
2. Name it: case_semifinal_gdpc.pdf
3. Place it in this directory: public/case/

Once uploaded, the button will link to this file and GDPC semifinalists
will be able to download the semifinal case from their dashboard.

Note: The button only appears for:
- Teams in the GDPC (Geothermal Development Plan Competition) category
- Teams that qualified for the semifinals
